# Flutter Platform Integration

A practical index of the boundaries between Flutter and its host platforms:
message channels, native interop, plugin architecture, platform runners,
browser integration, and embedded native views. Browse a category below, then
open a topic for focused notes on how Dart code connects to platform APIs,
toolchains, and lifecycles.
