# Flutter Widgets

A practical index of Flutter widgets, closely related framework APIs, and a
small number of architectural concepts, grouped by the role they play in an
interface. Category pages explain how the entries fit together. Leaf entries
are listed directly in these indexes; only categories have their own pages.
