# Flutter Layout Constraints

A practical index of how Flutter negotiates geometry, positions boxes, lays out
flex and stack children, adapts to available space, and constructs scrolling
viewports. Browse a category below, then open a topic for focused notes on the
layout contract, widget, render object, or failure mode.
