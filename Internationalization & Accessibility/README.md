# Flutter Internationalization & Accessibility

A practical index of Flutter localization, locale-aware formatting,
bidirectional layout, semantics, inclusive visual and input behavior, and
accessibility testing. Browse a category below, then open a topic for focused
notes and examples.

- [Text Direction](<Text Direction/README.md>) — Building layouts and content that adapt correctly between left-to-right and right-to-left reading directions
