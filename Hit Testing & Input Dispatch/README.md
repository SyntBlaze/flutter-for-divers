# Flutter Hit Testing & Input Dispatch

A practical index of how Flutter receives device input, finds its target,
dispatches pointer events, resolves gestures, tracks mouse interaction, routes
keyboard input, and exposes actions to accessibility services. Browse a
category below, then open a topic for focused notes on that part of the input
system.

```text
engine input -> pointer conversion -> hit test -> pointer dispatch -> gesture arena
                                      |                |
                                      v                v
                               hit test path       routes and listeners

keyboard -> focus tree -> shortcuts -> intents -> actions
accessibility service -> semantics action -> application callback
```
