A practical index of the native runtime beneath the Flutter framework: engine
and isolate lifecycles, the engine thread model, rendering backends, resource
loading, and platform integration boundaries. Browse a category below, then
open a topic for focused notes on how framework work reaches the host platform
and graphics stack.

> Engine behavior crosses Dart, native, and graphics boundaries. Diagnose a
> problem at the boundary where ownership changes, respect thread-affinity and
> lifecycle contracts, and measure frame-critical work on representative
> devices.
